# SmartTranslate 1.2.0 真机验收清单

> 逐项照着点, 每项 = 一句操作 + 一句预期。预计 15-25 分钟。
> A 组是历史修复复测, 升级后必须过一遍; B-G 组是 1.2.0 新功能与回归抽查。

## 前置: 升级到 1.2.0

- [ ] 工具 → 插件 → 右上角齿轮 → "Check for Updates", 升级到 1.2.0 → 插件卡片版本号显示 1.2.0
- [ ] 重启 Zotero → 重启后插件列表里 SmartTranslate 仍在且已启用
- [ ] 编辑 → 设置 → SmartTranslate: 确认 API Key 已填, 接口地址与模型未变 → 设置页正常打开且配置都在

## A. 历史修复复测 (六项)

- [ ] 侧栏显示: 双击打开一篇能正常打开的 PDF, 看右侧条目面板 → "SmartTranslate" 侧栏出现, 含引擎下拉、翻译按钮、原文框、译文框
- [ ] 侧栏交互: 在侧栏原文框粘贴一段英文, 点"翻译"按钮 → 译文框流式出中文, 结束后状态行显示"已完成 · Engine 1"
- [ ] 重复句秒回: 同一句英文再划一次 → 弹窗瞬间出结果, 无等待感 (缓存命中, 不发请求)
- [ ] 长译不阻塞: 划选一整段长文本翻译 → 翻译进行中 Zotero 界面不卡, 仍可滚动页面、切换标签
- [ ] 拼接缓存: 划第一段点"＋拼接", 再划第二段点"＋拼接", 点"翻译拼接" → 两段合并成一次翻译, 缓冲不丢
- [ ] 进度窗文字更新: 右键条目 → "SmartTranslate: 阅读助手（摘要/创新点/方法）" → 进度窗文字随进度逐块刷新, 不残留上一块的旧文案

## B. 新功能: 翻译取消

- [ ] 弹窗停止按钮: 在 PDF 里划选一段英文, 趁翻译还在出字时看弹窗 → 弹窗里出现"停止"按钮
- [ ] 弹窗取消效果: 点"停止" → 请求立刻中止, 已流出的部分译文保留, 状态显示"已取消" (中性提示, 不是红色报错)
- [ ] 侧栏按钮变化: 翻译进行中看侧栏 → "翻译"按钮已变成"停止"
- [ ] 侧栏取消效果: 点侧栏"停止" → 翻译中止, 状态行显示"已取消"

## C. 新功能: 未配置密钥引导

- [ ] 清空 Key 触发: 编辑 → 设置 → SmartTranslate, 清空 API Key, 回 PDF 划选一段英文 → 弹窗显示错误提示, 提示旁出现"打开设置"按钮
- [ ] 一键跳转: 点"打开设置" → 直接打开插件的设置页
- [ ] 侧栏引导: 在侧栏里翻译一次 → 状态行错误文案旁同样出现"打开设置"按钮
- [ ] 恢复现场: 把 API Key 填回去, 再划词一次 → 恢复正常翻译 (务必做, 别忘了)

## D. 新功能: Info 区译文行

- [ ] 写入标题译文: 选中一条有英文标题的文献, 右键 "SmartTranslate: 翻译标题（写入条目）" → 右侧 Info 区底部出现"标题译文"一行, 内容即译文
- [ ] 写入摘要译文: 右键 "SmartTranslate: 翻译摘要（写入条目）" → Info 区底部出现"摘要译文"一行
- [ ] 条目列表列: 条目列表里右键列头 → 勾选"标题译文" → 新列出现, 值与 Info 区一致
- [ ] 英文界面抽查 (可选): 把 Zotero 界面切到英文看 Info 区 → 两行显示 Title (Translation) / Abstract (Translation)

## E. 新功能: 多选批量写入条目

- [ ] 多选批量: 条目列表 Ctrl 多选 3 条以上 → 右键 "SmartTranslate: 翻译标题（写入条目）" → 进度窗逐条推进, 一条写完再翻下一条
- [ ] 完成摘要: 等批量跑完 → 进度窗显示"完成 X/Y · 跳过 Z · 失败 W", 三数之和等于选中条数
- [ ] 抽查结果: 随机点开两条 → Info 区"标题译文"行已有值
- [ ] 已知行为确认: 批量会处理附件条目的标题并写入附件自身 → 属预期行为, 不算缺陷, 不用回报

## F. 新功能: Alt+B 双语侧栏开关

- [ ] 阅读器内切换: 在打开的 PDF 里按 `Alt+B` → 双语侧栏弹出; 再按一次 → 收起
- [ ] 非阅读器场景: 库视图的条目列表标签下按 `Alt+B` → 无任何反应, 属正常设计

## G. 回归抽查

- [ ] 中文选区跳过: 划选一段中文 → 弹窗提示"检测到中文，已跳过翻译（可在设置中关闭）", 不发翻译请求
- [ ] 批量翻译导出仍在: 右键条目 → 菜单里仍有 "SmartTranslate: 批量翻译导出（双语 Markdown）"
- [ ] 阅读助手菜单仍在: 右键条目 → 菜单里仍有 "SmartTranslate: 阅读助手（摘要/创新点/方法）"

## 发现问题怎么回报

1. 记下现象: 第几组第几项 + 预期是什么 + 实际是什么 (能截图更好, 截窗口全貌);
2. 帮助菜单 → 调试输出日志 → 启用输出 → 复现一次问题 → 复制含 SmartTranslate 的报错行;
3. 把现象和报错一并发出, 等修复。
