# SmartTranslate 1.3.0 真机验收清单

> 逐项照着点, 每项 = 一句操作 + 一句预期。预计 15-25 分钟。
> A 组是 1.2.0 功能回归抽查, 升级后必须过一遍; B-D 组是 1.3.0 新功能; E 组是通用回归。

## 前置: 升级到 1.3.0

- [ ] 工具 → 插件 → 右上角齿轮 → "Check for Updates", 升级到 1.3.0 → 插件卡片版本号显示 1.3.0
- [ ] 重启 Zotero → 重启后插件列表里 SmartTranslate 仍在且已启用
- [ ] 编辑 → 设置 → SmartTranslate: 确认 API Key 已填, 接口地址与模型未变 → 设置页正常打开且配置都在

## A. v1.2.0 功能回归抽查 (五项)

- [ ] 列选择器两列: 条目列表里右键列头 → 勾选"标题译文"/"摘要译文" → 两列出现, 已有译文的条目列里有值
- [ ] Info 区译文行: 点开一条已写过译文的条目 → Info 区底部仍有"标题译文"/"摘要译文"两行
- [ ] 右键写入条目: 右键一条有英文标题的文献 → "SmartTranslate: 翻译标题（写入条目）" → 翻译完成后 Info 区底部出现"标题译文"一行
- [ ] Alt+B: 在打开的 PDF 里按 `Alt+B` → 双语侧栏弹出; 再按一次 → 收起
- [ ] 弹窗停止按钮: 划选一段英文, 趁翻译还在出字时点弹窗"停止" → 请求立刻中止, 已流出的部分译文保留, 状态显示"已取消"

## B. 新功能: 翻译历史

- [ ] 产生记录: 划词翻译几句英文 (侧栏手动翻译也算) → 翻译正常出结果, 无报错
- [ ] 展开历史: 打开条目侧栏 (Alt+B), 点底部"历史"按钮 → 列表展开, 刚才几句都在, 每条显示原文前 40 字符与时间
- [ ] 点击回填: 点历史里任意一条 → 原文与译文分别回填到侧栏上下两框, 不自动触发翻译
- [ ] 重启仍在 (清空前做): 重启 Zotero → 再点开"历史" → 刚才的记录仍在
- [ ] 清空: 点"清空" → 列表清空, 显示"暂无翻译历史"
- [ ] 超长不记录: 划选一段超 5000 字符的超长文本翻译, 再开历史 → 这条没出现在历史里, 其他记录正常
- [ ] 批量导出不写入: 多选条目右键 "SmartTranslate: 批量翻译导出（双语 Markdown）", 跑完再开历史 → 导出内容没有混进历史列表

## C. 新功能: 术语库

- [ ] 加一条术语: 编辑 → 设置 → SmartTranslate, 在"术语库"文本框里加一行 `mycorrhiza = 菌根` (可用你自己文献里的词), 点别处触发自动保存 → 保存无报错
- [ ] 术语生效: 回 PDF 划选一个含该词的句子 → 译文采用你的译法 (该词译作"菌根"), 不是模型自由发挥
- [ ] 坏行不阻断: 在术语库里补一行故意写错的 (缺 `=`), 保存 → 保存不报错, 原来那条术语划词仍生效
- [ ] 注释行 (可选): 加一行 `# 这是注释` 保存 → 无报错, 注释行不参与翻译

## D. 新功能: 翻译风格

注意: 会话缓存按"引擎 + 模型 + 语言对 + 原文"命中, 同一句在同一会话内换风格会秒回旧译文, 对比请用本次会话还没翻过的新句子 (或先重启 Zotero 清缓存)。

- [ ] 直译更逐字: 设置里把"翻译风格"切成"直译", 划选一句没翻过的英文 → 译文贴着原文语序走, 明显比标准风格更逐字
- [ ] 自定义生效: 风格切到"自定义", 在出现的 prompt 框里写一句风格要求 (如"译文口语化, 像给同学讲解"), 保存后划一句新英文 → 译文按你写的要求走
- [ ] 切走再切回: 风格临时切回"标准", 再切回"自定义" → 刚写的 prompt 原样还在
- [ ] 回到标准: 风格切回"标准", 划一句本次会话没翻过的英文 → 译文风格与升级前一致 (标准不追加任何风格指令)

## E. 通用回归

- [ ] 中文选区跳过: 划选一段中文 → 弹窗提示"检测到中文，已跳过翻译（可在设置中关闭）", 不发翻译请求
- [ ] 批量翻译导出仍在: 右键条目 → 菜单里仍有 "SmartTranslate: 批量翻译导出（双语 Markdown）"
- [ ] 阅读助手菜单仍在: 右键条目 → 菜单里仍有 "SmartTranslate: 阅读助手（摘要/创新点/方法）"

## 发现问题怎么回报

1. 记下现象: 第几组第几项 + 预期是什么 + 实际是什么 (能截图更好, 截窗口全貌);
2. 帮助菜单 → 调试输出日志 → 启用输出 → 复现一次问题 → 复制含 SmartTranslate 的报错行;
3. 把现象和报错一并发出, 等修复。
